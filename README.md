## Описание проекта

**Bomberman Trading System** - это продвинутая мультитаймфреймовая торговая система, использующая синхронизацию трех таймфреймов (30м, 15м, 5м) и уникальную комбинацию индикаторов для обнаружения точек входа с высоким потенциалом. Система включает как модуль бэктестирования, так и реального торгового бота.

**⚠️ Важное примечание:** Система находится в активной доработке и тестовом режиме. Все параметры требуют дальнейшей оптимизации и подгонки под конкретные рыночные условия.

## Ключевые особенности

### 📊 Мультитаймфреймовый анализ
- **30-минутный таймфрейм**: BOP индикатор (Balance of Power)
- **15-минутный таймфрейм**: Mean Reversion каналы (Bollinger-like)
- **5-минутный таймфрейм**: Donchian каналы (прорывы)
- **Синхронизация**: Walk-forward метод для предотвращения look-ahead bias

### ⚙️ Уникальные индикаторы

#### **BOP (Balance of Power)**
```python
df['bop'] = (close - open) / (high - low)
```
Индикатор, показывающий соотношение сил быков и медведей внутри свечи.

#### **Mean Reversion каналы**
```python
upper = SMA + 2 * STD
lower = SMA - 2 * STD
```
Статистические каналы для определения перекупленности/перепроданности.

#### **QML (Quasi-ML) - Квази-машинное обучение**
```python
def detect_qml_bull(df, i, order=3, recency=20):
    # Определение паттерна "более высокий минимум"
    if low2 < low1 and low3 > low2:
        return low2
```
Метод для обнаружения структурных разворотов без сложных ML алгоритмов.

### 🤖 Интеллектуальный вход в позицию
**LONG условия:**
1. BOP > 0 (преобладание быков)
2. Цена находится у нижней границы Mean Reversion канала
3. Прорыв выше Donchian high предыдущей свечи

**SHORT условия:**
1. BOP < 0 (преобладание медведей)
2. Цена находится у верхней границы Mean Reversion канала
3. Прорыв ниже Donchian low предыдущей свечи

## Параметры системы

### Параметры бэктеста (оптимизируются грид-поиском):
```python
PARAMS = {
    'mr_period': [14, 30, 45],      # Период Mean Reversion
    'mr_mult': [1.5, 2.5],          # Множитель STD для каналов
    'dc_period': [20, 14, 38],      # Период Donchian
    'bop_smooth': [1, 2],           # Сглаживание BOP
    'tolerance': [0.015, 0.002, 0.01],  # Допуск для входа
    'direction': ['both']           # Направление торговли
}
```

### Параметры реального бота:
```python
SYMBOL = 'LTCUSDT'          # Торговый символ
INTERVAL = '1h'             # Таймфрейм анализа
EMA_PERIOD = 100            # Период EMA
BB_STD = 2.0                # Стандартное отклонение для BB
ATR_SL_MULT = 1.5           # Множитель ATR для стоп-лосса
RR = 2                      # Risk/Reward ratio
QML_ORDER = 3               # Порядок для QML
LEVERAGE = 20               # Плечо
RISK_PERCENT = 0.01         # Риск на сделку (1%)
```
